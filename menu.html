Opciones

Header

header (o cabecera) en programación es un bloque de datos o código situado al principio de un archivo, mensaje o página para organizar la información y guiar al sistema sobre cómo procesar el resto.

Nav

El elemento nav en HTML representa una sección de una página web que contiene enlaces de navegación.

Article

La etiqueta article en HTML representa un bloque de contenido autónomo e independiente. Significa que el texto o los elementos dentro de ella tienen sentido por sí mismos y se pueden leer o compartir sin depender del resto de la página.
